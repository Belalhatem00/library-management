# نظام إدارة مكتبة (Library Management System)

مشروع C++ متوسط المستوى: برنامج ترمينال لإدارة مكتبة صغيرة. كتب، أعضاء، إعارة وإرجاع، بحث، وحفظ البيانات في ملفات عشان ماتضيعش لما تقفل البرنامج.

## المميزات

- إضافة وحذف الكتب والأعضاء
- إعارة كتاب لعضو وإرجاعه (مع منع الحالات الغلط: كتاب معار مرتين، حذف كتاب معار، حذف عضو عنده كتب)
- بحث جزئي في عنوان الكتاب أو اسم المؤلف، مش حساس لحالة الحروف
- حفظ تلقائي في ملفات نصية (`data/books.txt` و `data/members.txt`) بعد كل تعديل (إضافة أو حذف أو إعارة أو إرجاع)، وتحميلها عند التشغيل. مفيش خطوة حفظ يدوية محتاجة تفتكرها
- اختبارات للمنطق الأساسي

## التشغيل

محتاج مترجم g++ (أو أي مترجم C++17) و make.

```bash
make          # بناء البرنامج
./library     # تشغيل البرنامج
make test     # بناء وتشغيل الاختبارات
```

من غير make، ممكن تترجم مباشرة:

```bash
g++ -std=c++17 src/*.cpp -o library
./library
```

## استخدام البرنامج

لما البرنامج يفتح هيظهر قايمة بالأرقام: اكتب رقم العملية واتبع الأسئلة. الحفظ تلقائي بعد أي تعديل تعمله، وعند الخروج بيتأكد تاني، فتاني مرة تفتح فيها البرنامج هيلاقي البيانات زي ما سابها.

## هيكل المشروع

```
src/
  Book.h / Book.cpp       : كلاس الكتاب: بياناته وحالة إعارته
  Member.h / Member.cpp   : كلاس العضو: اسمه والكتب اللي معاه
  Library.h / Library.cpp : منطق الإدارة: إضافة، بحث، إعارة، حفظ وتحميل
  main.cpp                : القائمة التفاعلية في الترمينال
tests/
  tests.cpp               : اختبارات على الإضافة والبحث والإعارة والحفظ
data/                     : ملفات البيانات بتتعمل هنا مع أول تعديل
```

## أهم المفاهيم اللي المشروع بيتمرن عليها

- **Classes وتقسيم الكود** على ملفات header و cpp
- **std::vector** لتخزين الكتب والأعضاء، و **std::string** للنصوص
- **مراجع (references) ومؤشرات (pointers)**: الدوال بترجع مرجع أو مؤشر للعنصر اللي جوه الفيكتور
- **التعامل مع الملفات**: `std::ofstream` / `std::ifstream`، وتنسيق نصي بسيط مع معالجة الرموز الخاصة
- **معالجة الأخطاء**: الإعارة والإرجاع بيرجعوا رسالة خطأ بدل ما البرنامج يقع
- **std::filesystem** لإنشاء مجلد البيانات لو مش موجود

## ملاحظات

- التنسيق المستخدم في ملفات البيانات سطر لكل عنصر، والحقول مفصولة بـ `|` (الرموز `|` و `%` جوه النصوص بتتحول لصيغة آمنة عشان الملف ميبوظش).
- أرقام الكتب والأعضاء بتزيد تلقائياً ومبتتكررش أبداً، حتى لو اتمسح عنصر واتقفل البرنامج واتفتح تاني (الرقم التالي محفوظ في الملف نفسه).
